
checklist for new language:
    -package name
    -app name
    -top bar flag emoji (home.dart line 289)
    -set text direction if needed (flashcard.dart line 84)
    -delete output folder
    -update generate_data.js to output specific language
    -generate data using generate_data.js
    -update launcher icon
    -run: dart run flutter_launcher_icons
    -bump version if needed
    -set up google ads
    -update google ads ids (home.dart line 28)
    -update google ads app id (android: AndroidManifest.xml line 37)
    -flutter build appbundle --release
    -copy output to drive/flamingo/data


useful commands:
    -create pem file: "C:\Program Files\Android\Android Studio\jbr\bin\java.exe" -jar pepk.jar --keystore=FlamingoKeystore.jks --alias=wordsmithkeystore --output=FlamingoKeystore.pem --rsa-aes-encryption --encryption-key-path=encryption_public_key.pem
    -generate upload key: keytool -genkey -v -keystore user-upload-key.jks -alias user-upload-alias -keyalg RSA -keysize 2048 -validity 10000
